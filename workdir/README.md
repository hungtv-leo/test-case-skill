# workdir (skill sandbox)

All files generated by the `/self-test-cases` skill go **here**, not in the
project root.

```
workdir/
├── tests/<feature>/     # test files + cases.json
├── pytest.ini           # only if needed (never at project root)
├── .report.json
├── results.json
└── .selftest_tmp/       # Excel handover (temporary)
```

This folder is gitignored. Do not commit it.
